Commands for create migration and update database

######
cd to Infrastructure project folder

you can only update DB:
dotnet ef database update -s ../../app/Server/Blazorit.Server.csproj --context IdentDbContext
dotnet ef database update -s ../../app/Server/Blazorit.Server.csproj --context DomDbContext

if you want create migrations, than first delete old migrations from folder and apply these commands:
dotnet ef migrations add Init -s ../../app/Server/Blazorit.Server.csproj --context IdentDbContext
dotnet ef migrations add Init -s ../../app/Server/Blazorit.Server.csproj --context DomDbContext
