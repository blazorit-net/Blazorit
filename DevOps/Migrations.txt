Commands for create migration and update database

IN VS PMC:
Add-Migration InitialCreate
Update-database

OR 

for CLI:
dotnet ef migrations add InitialCreate
dotnet ef database update


######
cd to Infrastructure project folder

dotnet ef database update -s ../../app/Server/Blazorit.Server.csproj
dotnet ef migrations add CreateEcommerceEntities -s ../../app/Server/Blazorit.Server.csproj
dotnet ef database update -s ../../app/Server/Blazorit.Server.csproj
